# 更新日志 (Changelog)

所有关键版本的更新历史均记录于此。

## [1.1.0] - 2026-11-10

### ✨ 功能增强与缺陷修复
- **词典扩充至 514 条**：深度补全模型额度状态（充裕/适中/紧张）、暂未开放、限额注意等核心状态词条；
- **重构 DOM 遍历与属性监听**：
  - 攻克 TreeWalker 仅抓取文本节点的盲区，实现两级元素与属性（`title`、`placeholder`、`aria-label`）全覆盖；
  - 彻底汉化全界面 53+ 处图标按钮的悬停提示（复制、固定/归档会话、更多选项、表格操作、侧边栏切换等）；
- **动态正则修复与补全**：
  - 修复耗时统计（`Worked for`）多重反斜杠转义失效缺陷；
  - 新增相对时间（`Xm/h/d ago`）与运行状态前缀（`Running ...`）智能匹配；
- **纯粹原生外观保障**：
  - 彻底去除泛黄暖纸样式与外部 CSS 干扰，100% 保持官方原版原生视觉与深浅色模式。

## [1.0.0] - 2026-11-10

### 🚀 初始版本发布
- **免 TUN 网络引擎**：支持 10808 本地出海端口自动检测、用户级注册表环境变量配置与连通性自测。
- **双轨制汉化套件**：
  - 支持 CDP 动态热注入与当前运行窗口即刻汉化；
  - 支持基于 Electron 官方 ASAR 的静态持久化重构与 Windows 内核级重启替换队列。
- **487+ 项核心词典全覆盖**：
  - 项目卡片右键菜单（复制项目名称、项目设置、在文件资源管理器中显示等）；
  - 顶部系统菜单栏（视图、窗口、版本号、检查更新等）；
  - 斜杠指令浮层（btw、goal、compact、schedule、browser、plan、grill-me、teamwork、boost 等）；
  - 内置技能说明（包含被截断带 `...` 的模糊前缀适配）。
- **快捷方式合规治理**：
  - 确保桌面只保留 100% 官方原厂直连快捷方式 `Antigravity.lnk`；
  - 彻底清理任何 `.bat` 或套壳启动器。
- **Antigravity Skill 集成**：提供 `/antigravity-setup` 与 `/agy-setup` 专属指令。
