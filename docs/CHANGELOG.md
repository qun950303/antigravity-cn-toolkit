# 更新日志 (Changelog)

所有关键版本的更新历史均记录于此。

## [1.2.0] - 2026-11-10

### 🚀 终极统一与完全体引擎升级 (Single Source of Truth)
- **确立全局唯一真实源**：
  - 彻底改造全局技能目录（`antigravity-setup` 与 `agy-setup`），所有调用全部 100% 统一指向主工程入口 `node "D:\antigravity-cn-toolkit\src\index.js"`；
  - 彻底根除技能脚本双重副本反向覆盖的历史隐患。
- **融合原版成熟的完全体汉化引擎**：
  - 引入 WeakMap 状态追踪与 `data-ag-orig-` 属性双向解耦机制，预防 React 重新渲染造成的内存泄露与死循环；
  - 实装 O(N·深度) 脏根节流防抖队列与 `requestAnimationFrame` 驱动，动态监听极端丝滑；
  - 彻底攻克 TreeWalker 仅找文本节点的缺陷，实现全界面 53+ 处无字图标悬停提示（`aria-label`/`title`/`placeholder`）深度穿透汉化；
  - 内置死锁自愈机制（`initDeadlockHealer`），防止设置面板焦点逃逸卡死。
- **坚守红线规范**：
  - 严格保持 100% 官方原厂原生外观，0 暖纸底色、0 蜡封边框，契合原生深浅色视觉质感；
  - 严格保持 514+ 项全量最新基准词典与动态耗时/相对时间正则。

- **纯粹原生外观保障**：
