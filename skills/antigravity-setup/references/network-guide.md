# Antigravity 免 TUN 模式出海网络架构指南

## 1. 架构核心思想
- **拒绝整机接管**：不开启 TUN 虚拟网卡，避免修改系统全局网络协议栈，防止游戏、局域网共享或其他软件受到影响。
- **精准通道继承**：利用 Windows 用户级环境变量，让 Antigravity 主进程、渲染进程、插件子进程及内嵌的 Node.js / CLI 自动继承 `127.0.0.1:10808` 代理通道。

## 2. 环境变量规范
- `HTTP_PROXY` = `http://127.0.0.1:10808`
- `HTTPS_PROXY` = `http://127.0.0.1:10808`
- `ALL_PROXY` = `socks5://127.0.0.1:10808`

## 3. 故障排查与速查
1. 若无法连接，首先检查本地 Xray / V2Ray 客户端是否开启并正常监听 10808 端口。
2. 运行 `node scripts/setup-network.js` 进行一键连通性自检。
